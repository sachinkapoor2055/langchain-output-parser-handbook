# LangChain — Output Parsers

My digital notes and practical experiments while learning **Output Parsers in LangChain**.

This repository focuses on understanding how LangChain Output Parsers transform raw language model responses into structured, validated, and application-ready data.

## 📚 Notebooks

| # | Notebook | Description |
|---|---|---|
| 1 | `output_parser_overview.ipynb` | An introduction to LangChain Output Parsers and their role in transforming LLM responses into usable data. |
| 2 | `str_output_parser.ipynb` | Explores `StrOutputParser` for extracting clean string outputs from language model responses. |
| 3 | `json_output_parser.ipynb` | Demonstrates using `JsonOutputParser` to convert LLM responses into structured JSON data. |
| 4 | `structured_output_parser.ipynb` | Explores techniques for parsing LLM responses into predefined structured formats. |
| 5 | `pydantic_output_parser.ipynb` | Demonstrates using `PydanticOutputParser` to validate and parse LLM responses into typed Python objects. |
